Projeto desenvolvido durante os estudos de **Angular**, com o objetivo de aprender e praticar os principais conceitos do framework, como componentes, templates, data binding, diretivas, serviços e organização de aplicações. O Angular é um framework desenvolvido pelo Google para criação de aplicações web modernas e escaláveis.

##  Tecnologias Utilizadas

- Angular
- TypeScript
- HTML5
- CSS3
- Node.js
- Angular CLI
